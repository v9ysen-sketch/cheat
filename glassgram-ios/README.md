# GlassGram для iOS

Мод [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) (GPL-2.0), версия 13.0.1. Используется
последний коммит, который собирается Xcode 26.6: он есть на macOS-машинах GitHub Actions. Хеш коммита
записан в `UPSTREAM_COMMIT`.

## Что изменено

- **Стиль:** синее стекло по умолчанию днём и ночью (тонированная тёмная тема с синим акцентом).
  В настройках есть ещё 12 стилей, у каждого свой акцент, градиент исходящих сообщений и градиентные обои.
- **Аватарки:** 5 форм, от квадрата до круга.
- **Удалённые сообщения:** остаются на устройстве с пометкой «удалено» перед временем.
- **Режим призрака:**
  - не отправлять «прочитано»;
  - смотреть истории незаметно;
  - всегда «не в сети»;
  - не показывать «печатает…».
- **Интерфейс:** скрыть истории над чатами, время сообщений с секундами.
- **Название и иконка:** название GlassGram, своя иконка (стеклянная плитка с буквой G).
  Альтернативные иконки Telegram убраны.
- **Экран настроек:** **Настройки → GlassGram**.

Плагинов на iOS нет: Apple запрещает загружать и подменять код во время работы приложения.
Liquid Glass на iOS 26 рисует сама система.

## Сборка

Workflow **Build GlassGram iOS** (`.github/workflows/glassgram-ios.yml`) собирает неподписанный
`GlassGram.ipa` на `macos-26`. Ему нужны те же секреты, что и Android-сборке: `GLASSGRAM_API_ID`
и `GLASSGRAM_API_HASH`. Сборка занимает 1–3 часа.

## Установка через Sideloadly (Windows или Mac)

1. Скачай `GlassGram.ipa` из раздела Artifacts нужного запуска workflow.
2. Открой Sideloadly, подключи iPhone кабелем и введи свой Apple ID.
3. В **Advanced options**:
   - включи **Remove app extensions**: на бесплатный Apple ID можно зарегистрировать только
     несколько ID приложений;
   - оставь включённой опцию смены Bundle ID.
4. Нажми **Start**. На iPhone открой **Настройки → Основные → VPN и управление устройством**,
   доверь своему Apple ID, а в iOS 16 и новее включи **Режим разработчика**.
5. Подпись на бесплатном Apple ID живёт 7 дней. Потом приложение нужно переподписать: данные
   при этом сохранятся.

AltStore тоже подойдёт: он сам продлевает подпись по Wi-Fi.
