# GlassGram

Визуальный мод Telegram для Android. Собран из официальных открытых исходников
[DrKLO/Telegram](https://github.com/DrKLO/Telegram) (лицензия GPL-2.0), версия 13.2.2,
коммит из файла `UPSTREAM_COMMIT`.

## Что изменено

| | |
|---|---|
| **Тема** | Синее «жидкое стекло»: тёмно-синие (navy) поверхности, голубые акценты, исходящие пузыри с градиентом от синего к голубому, 4-цветные градиентные обои. Тема включена по умолчанию и днём, и ночью. |
| **Стекло** | Эффект Liquid Glass (Android 13+) и размытые панели в чатах включаются при первом запуске. Панели сделаны прозрачнее, у стекла голубая обводка. |
| **Аватарки** | Квадратные со скруглёнными углами: в списке чатов, в чатах, в профилях и в кольцах историй. |
| **Название и иконка** | GlassGram, своя иконка (стеклянная плитка с буквой «G»). Пакет `com.glassgram.messenger`, поэтому мод ставится рядом с обычным Telegram. |
| **Удалённые сообщения** | Сообщения, которые удалил собеседник, остаются на устройстве с пометкой «удалено» рядом со временем. Функция включается в настройках мода. |
| **Плагины** | Плагины exteraGram (`.plugin`, Python 3.13). Это собственная реализация их публичного API, подробности в разделе «Плагины». |
| **Прочее** | Отключены проверка обновлений Telegram, покупки через Google Play, passkeys и вход через Firebase. Всё это работает только в официальном приложении. Минимальная версия Android 7.0, поддерживаются только 64-битные устройства (этого требует Python). |

## Настройки мода

Пункт **Настройки → GlassGram** в самом верху списка:

- **Жидкое стекло:**
  - «Состояние стекла» показывает, работает ли эффект и что ему мешает: версия Android, класс устройства, энергосбережение;
  - «Принудительное стекло» (включено по умолчанию) включает стекло на любом устройстве и при энергосбережении. Без этой опции Telegram отключает стекло на устройствах, которые считает слабыми;
  - отдельные переключатели Liquid Glass и размытия панелей;
  - сила преломления (5 уровней) и прозрачность стекла (4 уровня).
- **Стиль, 15 вариантов:** синее, голубой лёд, фиолетовое, изумруд, закат, золото, AMOLED, розовое, рубин, апельсин, мята, графит, неон, светлое стекло, белое (классика).
- **Форма аватарок:** 5 вариантов, от квадрата до круга.
- **Скругление сообщений** и **размер текста.**
- **Интерфейс:** скрыть истории над чатами, скрыть Premium и Звёзды в настройках, время сообщений с секундами.
- **Режим призрака:** не отправлять «прочитано», смотреть истории незаметно, всегда «не в сети», не показывать «печатает…».
- **Удалённые сообщения:** сохранять, помечать, очистить пометки.
- **Плагины:** список, установка, включение и выключение, настройки плагина, удаление.

Liquid Glass (эффект преломления) работает на Android 13 и новее, размытие панелей на Android 12 и новее. Эффект виден на нижней панели вкладок, в шапке и кнопках чата, в меню вложений и в панели эмодзи.

## Плагины

Поддерживается подмножество API плагинов exteraGram по их
[документации](https://plugins.exteragram.app/docs). Это своя реализация, а не код exteraGram:
движок плагинов у exteraGram закрыт.

**Работает:**

- **Формат и загрузка.** Метаданные `__id__`, `__name__`, `__description__`, `__author__`,
  `__version__`, `__min_version__`. Класс плагина наследует `BasePlugin`, при загрузке
  вызывается `on_plugin_load`, при выключении `on_plugin_unload`.
- **Хуки событий:**
  - `add_hook` с колбэками `pre_request_hook`, `post_request_hook`, `on_update_hook`,
    `on_updates_hook`;
  - `add_on_send_message_hook` с колбэком `on_send_message_hook`;
  - результаты через `HookResult` со стратегиями `DEFAULT`, `CANCEL`, `MODIFY`, `MODIFY_FINAL`.
- **Хуки Java-методов в стиле Xposed** (через Pine): `hook_method`, `MethodHook`,
  `MethodReplacement`, `hook_all_methods`, `hook_all_constructors`, `HookFilter`.
- **Настройки плагина:** `create_settings` с элементами `Header`, `Switch`, `Selector`, `Input`,
  `Text`, `Divider`; значения через `get_setting` и `set_setting`.
- **Вспомогательные модули:**
  - `client_utils`: `send_message`, `send_text`, `send_request`, `run_on_queue`, `get_*_controller`,
    `get_last_fragment` и другие;
  - `android_utils`, `hook_utils`, `file_utils`;
  - `ui.bulletin` (`BulletinHelper`), `ui.alert` (`AlertDialogBuilder`);
  - `markdown_utils` и `extera_utils.text_formatting` (HTML и Markdown).
- **Доступ к Java** через `from java import jclass` (Chaquopy), а также `from org.telegram... import ...`.
- **Предустановленные библиотеки:** `requests`, `beautifulsoup4`, `packaging`.

**Не работает (пока):**

- пункты меню плагинов (`add_menu_item`): плагин их регистрирует, но в интерфейсе они не появляются;
- `Custom`-элементы настроек и вложенные экраны (`create_sub_fragment`);
- условия MVEL в `HookFilter.Condition`: такой фильтр всегда пропускает вызов;
- установка pip-зависимостей из `__requirements__`: если нужной библиотеки нет среди
  предустановленных, плагин не загрузится и покажет ошибку;
- плагины, которые обращаются к классам самого exteraGram (`com.exteragram...`).

Перехват методов (Pine) проверен на Android до 14. На более новых версиях `hook_method`
может не сработать, и тогда в списке у плагина будет ошибка.

**Установка плагина:** нажми на `.plugin`-файл в любом чате или открой
**Настройки → GlassGram → Плагины → Установить плагин**. Пример плагина лежит в
`glassgram/plugins/glass_tools.plugin`: команды `.ping` и `.glass`, подпись к сообщениям
и режим «не показывать „печатает…“».

⚠️ Плагин получает полный доступ к аккаунту. Ставь только те плагины, которым доверяешь.

## Как получить APK

### 1. Ключи API (обязательно)

Без своих ключей приложение не сможет войти в аккаунт, а официальные ключи Telegram в форках
использовать запрещено.

1. Зайди на <https://my.telegram.org> → **API development tools**.
2. Создай приложение (название любое, например GlassGram, платформа Android).
3. Скопируй **App api_id** (число) и **App api_hash** (строка).

Никому их не пересылай и не коммить в репозиторий.

### 2. Сборка через GitHub Actions (проще всего)

1. В репозитории открой **Settings → Secrets and variables → Actions → New repository secret**
   и добавь два секрета:
   - `GLASSGRAM_API_ID` со значением api_id;
   - `GLASSGRAM_API_HASH` со значением api_hash.
2. Открой **Actions → Build GlassGram → Run workflow**.
3. Через 1–3 часа (нативная часть собирается долго) APK появится в разделе **Artifacts** этого запуска.

### 3. Сборка у себя

Понадобятся JDK 17+, Python 3.13, Android SDK (build-tools 36.0.0, platform 36,
NDK 27.2.12479018, CMake 3.22.1), около 15 ГБ места на диске и 16 ГБ ОЗУ.

```bash
export ANDROID_HOME=~/Android/Sdk
GLASSGRAM_BUILD_PYTHON=$(which python3.13) GLASSGRAM_API_ID=12345 GLASSGRAM_API_HASH=0123abcd... ./glassgram/build.sh
# APK будет в glassgram-out/GlassGram-13.2.2.apk
```

Скрипт скачивает исходники Telegram на нужном коммите, применяет `glassgram.patch` и собирает APK.

## Установка

Скопируй APK на телефон и открой его. Нужно разрешить установку из неизвестных источников.
Мод встанет отдельным приложением и не заменит официальный Telegram.

## Ограничения

- **Push-уведомления.** Для них нужен собственный проект Firebase. Сейчас вместо него заглушка
  (`google-services.json`), так что уведомления приходят, только пока приложение работает в фоне.
  Если хочешь полноценные пуши, создай проект в Firebase для пакета `com.glassgram.messenger`
  и замени файл `TMessagesProj_App/google-services.json`.
- **Эффект Liquid Glass** работает на Android 13 и новее. На более старых версиях будет обычное размытие.
- **Подпись APK.** APK подписан тестовым ключом из исходников Telegram (`release.keystore`,
  пароль `android`). Для личного использования этого достаточно. Если будешь раздавать мод,
  сделай свой ключ.
- **Лицензия.** Telegram распространяется под GPL-2.0: если раздаёшь мод, его исходники
  (этот патч) тоже должны быть открыты.

## Как обновить мод на новую версию Telegram

1. Поменяй хеш коммита в `UPSTREAM_COMMIT`.
2. Запусти `build.sh`.
3. Если патч не применится, перенеси изменения вручную. Затронутые файлы перечислены в начале
   `glassgram.patch`.
